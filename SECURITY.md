# Security policy

## Supported versions

Security fixes go into the latest release.

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

E-mail **hello@indianopinion.org** with a description, the affected
version, and steps to reproduce. Please do not open a public issue for a
security problem.

We acknowledge reports within 3 working days and aim to ship a fix or a
mitigation within 30 days, sooner for anything that exposes unapproved
translations, bypasses a capability check, or lets model output reach a
page unsanitised. We credit reporters who want credit.
